SafeHarvest 智能合約測試操作說明
=================================

📘 測試目的
-----------
驗證整個 SafeHarvest 系統（三份合約）在 Hardhat 環境中運作邏輯正確：
- Factory（銀行工廠）能建立專案合約
- NFT 專案合約能收取 TWDT 投資金、分配 NFT
- 每年收益能正確依 NFT 數量與投資人比例分配

合約包括：
1. TWDT.sol — 模擬 ERC20 穩定幣
2. SafeHarvestFactory.sol — 工廠，用於創建專案
3. SafeHarvestNFT.sol — 每個專案的獨立收益合約


🧩 部署順序
-----------
1️⃣ 部署 TWDT ERC20：
   - deployer = 銀行平台帳號
   - 初始發行量：1,000,000 TWDT
   - address = twdtAddress

2️⃣ 部署 SafeHarvestFactory：
   - constructor 輸入：twdtAddress
   - address = factoryAddress

3️⃣ 由工廠創建 SafeHarvestNFT 專案：
   - 呼叫 factory.createProject(
       溫室建構費,
       每年營業額,
       投資人收益分成(%),
       利率(%),
       溢酬(%)
     )
   - 回傳 SafeHarvestNFT 專案合約地址 (projectAddress)


💰 測試錢包設定
---------------
- deployer：工廠擁有者
- investorA：第一位投資人
- investorB：第二位投資人

初始動作：
- deployer 將 TWDT 分配給 investorA、investorB 各 1000 TWDT
- investorA / B 需 approve 專案合約地址 projectAddress 為 spender


🧪 測試情境 Scenario 1：單一投資人年度收益
----------------------------------------
1. investorA 呼叫 SafeHarvestNFT.deposit(100 TWDT)
   → 預期：成功收款並 mint 1 枚 NFT 給 investorA
   → output: NFT ID #1 owner = investorA

2. 調用 SafeHarvestNFT.triggerYearlyUpdate()
   → year++
   → 自動計算該年度投資人收益
   → investorA 獲得分紅 TWDT（根據投資人分成%）

3. 呼叫 SafeHarvestNFT.getInvestorData(investorA)
   → 回傳：
     a. 投資人分成金額
     b. 累積償還本金
     c. 剩餘未償本金
     d. 剩餘未償本金 + 利率
     e. 當年買回總收益
     f. 殖利率（不買回）
     g. 總報酬率

4. 驗證 investorA 的 TWDT 餘額變化
   → 餘額增加符合預期收益


🧪 測試情境 Scenario 2：多投資人按 NFT 數量分紅
------------------------------------------------
1. investorA 呼叫 SafeHarvestNFT.deposit(200 TWDT)
   → mint 2 枚 NFT (#1、#2)
2. investorB 呼叫 SafeHarvestNFT.deposit(100 TWDT)
   → mint 1 枚 NFT (#3)
3. 呼叫 SafeHarvestNFT.triggerYearlyUpdate()
   → year++
   → 計算收益總額
   → 將收益平均分配到 3 枚 NFT
   → investorA 收到 2 份收益、investorB 收到 1 份收益

4. 驗證：
   - SafeHarvestNFT.year == 1
   - investorA TWDT 餘額：原餘額 + (2 * 分紅)
   - investorB TWDT 餘額：原餘額 + (1 * 分紅)

5. 調用 SafeHarvestNFT.getProjectStatus()
   → 回傳年度紀錄、剩餘本金、年化殖利率等數據


🕹️ Function 呼叫順序總覽
------------------------
1. deploy TWDT
2. deploy Factory (input = twdtAddress)
3. factory.createProject(...)
4. investorA.transfer / approve
5. investorA.deposit()
6. investorB.deposit()
7. SafeHarvestNFT.triggerYearlyUpdate()
8. SafeHarvestNFT.getInvestorData()
9. SafeHarvestNFT.getProjectStatus()


📈 輸入輸出摘要
---------------
- Input:
  (1) 溫室建構費 (uint)
  (2) 每年營業額 (uint)
  (3) 投資人收益分成百分比 (uint)
  (4) 利率百分比 (uint)
  (5) 溢酬百分比 (uint)

- Output:
  a. 投資人分成
  b. 累積償還本金(萬)
  c. 剩餘未償本金(萬)
  d. 剩餘未償本金 + 利率(萬)
  e. 買回價格(萬)
  f. 當年買回總收益
  g. 殖利率-不買回
  h. 當年買回總報酬率


✅ 預期結果
-------------
所有年度收益、NFT分紅、本金變動邏輯皆與公式計算一致。
cursor 依此 txt 內容操作 Hardhat，能驗證合約功能完整、可靠。
